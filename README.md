# 企业微信销售单推送机器人

Windows 桌面工具：从 EMS 读取销售详单，按 GUI 规则筛选，将晒单消息推送到企业微信群机器人；符合金额门槛且已成功晒单的单据可生成并推送喜报。

## 安装与启动

首次安装时双击 `一键安装并启动GUI.cmd`。电脑需要联网，并安装 Python 3.12 或更新版本；脚本未找到 Python 时会尝试通过 Windows `winget` 安装。脚本会在项目目录创建 `.venv`，安装运行和打包依赖，创建缺失的本地配置文件，构建独立 EXE 并启动 GUI。安装日志写入 `setup.log`。

首次安装完成后，直接双击根目录的 `企业微信销售推送.exe` 即可启动，不需要先打开命令行或手动激活 Python 环境。`启动桌面GUI.vbs` 也会优先启动此 EXE；若 EXE 尚未生成，则打开一键安装脚本。

EXE 使用同目录下的 `config.local.yaml`，以及 EMS 配置 `ems_config.json`。首次安装会从示例文件复制缺失的配置，不会覆盖已有文件。请在 GUI 中配置 EMS 账号、Webhook 和筛选规则。`store_mapping.yaml`、`templates/` 和 `var/` 也应保留在 EXE 同目录：它们分别提供机构映射、模板和本地数据库/推送状态。

真实账号、密码、Webhook 和本地运行状态只保存在本机，不要提交到 GitHub。首次连接前请保持 GUI 的“演练模式”开启，核对筛选规则与消息内容后再开启真实推送。

## GUI 功能

- EMS 只读登录及销售详单读取
- 多组规则、全部满足/任一满足组合和销售单号去重
- 销售机构、业绩机构、销售类型、金额、日期、商品、季号和出货组别条件
- 自定义晒单消息模板和预览
- 根据销售单金额门槛生成喜报图片并推送
- 推送记录、喜报已发送标记和重新扫描控制

销售类型编码为 `0=销售、1=换货、2=退货、3=预购`。销售机构和业绩机构是不同字段；机构名称及区域映射维护在 `store_mapping.yaml`。

## 筛选说明

筛选分为 EMS 查询条件和本地规则条件。GUI 会按协议支持情况将条件用于 EMS 查询，并在完整解码后按规则再次判断。部分商品字段不能可靠地由 EMS 过滤，必须保留本地判断；季号、出货组别的多个取值会分别查询并合并结果。不要把服务器返回结果当作所有本地条件均已满足的证明。

同一大规则内可选择整体满足（AND）或任一满足（OR）；多个启用的大规则按命中并集推送。同一订单命中多个规则仍按单号去重。若关闭“返回整单”，程序按本地商品条件保留命中商品行；仅有单头条件时不会猜测商品归属。

## 喜报和去重

喜报只会为符合金额门槛、且通过晒单规则并成功晒单的单据发送。状态页会在对应单据旁显示喜报是否已发送。

点击“清空全部推送状态”会同时清除普通晒单和喜报去重标记；重新扫描后，仍符合当前规则的单据可能再次推送晒单和喜报。该操作可能产生大量重复消息，请先确认重新读取起始日期，并在确认提示中核对影响范围。单独刷新状态只更新显示，不会清空记录。

## 开发与测试

```powershell
$env:PYTHONPATH = "src"
python -m pytest -q
python -m compileall -q src
```

Windows 默认临时目录权限不足时，可指定仓库内一个未使用的临时目录：

```powershell
python -m pytest -q --basetemp=tmp/pytest-run
```

重新构建 EXE：

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean 企业微信销售推送.spec
Copy-Item dist\企业微信销售推送.exe .\企业微信销售推送.exe -Force
```
