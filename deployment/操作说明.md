# EMS 销售晒单推送系统部署与操作说明

## 1. 交付包内容

- `src`：程序源码。
- `deployment\INSTALL_ENVIRONMENT.ps1`：安装 Python 虚拟环境和项目依赖。
- `deployment\START_WEB.ps1`：启动网页后台。
- `deployment\START_SCAN.ps1`：启动持续扫描和推送。
- `deployment\STOP_SCAN.ps1`：停止持续扫描。
- `deployment\config.example.yaml`：主配置模板。
- `deployment\ems_config.example.json`：EMS 账号配置模板。

交付包不包含任何真实 EMS 账号、企业微信 Webhook、后台账号密码、SQLite 数据库、推送记录、日志或抓包/导出数据。

## 2. 首次安装

在 Windows 10/11 x64 电脑上，以普通 PowerShell 打开交付目录，执行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\deployment\INSTALL_ENVIRONMENT.ps1
```

交付包已附官方 Python 3.13 x64 安装程序。安装 Python 后，脚本仍需要访问 Python 包仓库下载 Flask、SQLAlchemy、PyYAML 等依赖；若服务器不能联网，IT 需预先准备这些依赖的离线 wheel 包。

## 3. 填写配置

复制配置模板：

```powershell
Copy-Item .\deployment\config.example.yaml .\config.local.yaml
Copy-Item .\deployment\ems_config.example.json .\ems_config.json
```

编辑 `ems_config.json`，填写 EMS 账号、密码、服务器地址和端口。编辑 `config.local.yaml`，填写企业微信 Webhook、后台初始密码，并维护 `store_mapping` 的机构编号与中文店铺名关系。

首次验收保持 `runtime.dry_run: true`。确认规则、模板和 EMS 查询结果正确后，改为 `false` 才会真实发送企业微信消息。

## 4. 启动与操作

1. 运行 `deployment\START_WEB.ps1`，浏览器访问 `http://127.0.0.1:5000/login`。
2. 在网页“运行配置”保存 EMS 账号，并按需勾选中文店铺名显示。
3. 在“规则管理”配置销售机构与业绩机构筛选、金额和日期等条件。
4. 在“消息模板管理”使用 `{{ item.image_markdown }}` 显示图片。
5. 在“系统状态”点击开始扫描与推送，或运行 `deployment\START_SCAN.ps1`。

扫描状态每轮结束后写入数据库；刷新系统状态页面即可看到最新记录。

## 5. 网络与权限要求

- 服务器须能访问 EMS `giada-erp.redstone.com.cn:9999` 和 `:9100`。
- 若出现 `WinError 10013`，请由 IT 检查 Windows 出站防火墙、终端安全软件和运行账户的网络访问权限。
- 企业微信客户端必须能访问图片 URL 所在的内网服务，Markdown 图片才会正常显示。

## 6. 日常维护

- 停止扫描：网页系统状态点击停止，或运行 `deployment\STOP_SCAN.ps1`。
- 推送记录删除会同步删除本地去重状态，因此该订单可在下一轮重新推送。
- 请定期备份 `var\app.db`、`var\push-state.json` 和 `config.local.yaml`；不要将这些文件发送到公开渠道。
